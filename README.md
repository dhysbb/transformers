# transformers
 wordl - программа загадывает слово из словаря, пользователь вводит свое предположение, в ответ получает, какое место в рейтинге занимает его предположение. программ использует две модели. для каждое из моделей строится свой рейтинг. есть функции help и exit.
 search_in_article - пользователь задает вопрос по статье, которая есть в корпусе, получает ответ из топ5 самых близких чанков, внутри чанка топ3 самых близких предложений к ответу на вопрос.
